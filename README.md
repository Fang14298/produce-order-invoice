## ✨ ฟีเจอร์

* **อ่านข้อมูลสด ไม่ต้องมี backend เพิ่ม**: ดึงออเดอร์ทั้งหมดจากชีต `"รายการออเดอร์"` ของ Google Sheet เดียวกับ `produce-order` ผ่าน Google Visualization API (`gviz/tq`) — อ่านอย่างเดียว ปลอดภัย ไม่ต้องแก้ Apps Script ข้อกำหนดเดียวคือชีตต้องแชร์แบบ *"ทุกคนที่มีลิงก์ - ผู้มีสิทธิ์ดู"*
* **ค้นหา + เลือกออเดอร์**: ค้นหาด้วยเลขที่ออเดอร์ / ชื่อลูกค้า / เบอร์โทร กดเลือกจากรายการด้านซ้ายเพื่อขึ้นบิลด้านขวาทันที (ออเดอร์ล่าสุดอยู่บนสุด)
* **แปลงข้อความสรุปกลับเป็นตารางรายชิ้น**: อ่านคอลัมน์ `รายการสินค้าที่สั่ง` แล้วแยกกลับเป็นแถวสินค้า (ชื่อ/จำนวน/หน่วย/ราคาต่อหน่วย/จำนวนเงิน) ด้วย regex
* **แปลงวันที่จาก Google Sheets ให้อ่านง่าย**: คอลัมน์ที่เป็นชนิด Date ในชีต (เช่น `วันที่รับของ`, `วัน-เวลาสั่งซื้อ`) เมื่ออ่านผ่าน GViz จะได้ค่าดิบเป็นข้อความรูปแบบ `Date(YYYY,M,D)` หรือ `Date(YYYY,M,D,H,Mi,S)` (เดือนเริ่มนับที่ 0 ตามสเปคของ Google) ฟังก์ชัน `parseGvizDate()` ในหน้าเว็บจะแปลงค่านี้ให้เป็นรูปแบบไทยที่อ่านง่าย `DD/MM/YYYY` (เช่น `12/08/2026`) หรือ `DD/MM/YYYY HH:MM:SS` สำหรับคอลัมน์ที่มีเวลาด้วย โดยอัตโนมัติ
* **PromptPay Dynamic QR Code ล็อกยอด**: สร้าง QR ตามมาตรฐาน EMVCo ด้วยไลบรารี `qrcode-generator` (ออฟไลน์ ไม่พึ่ง API ภายนอก) ล็อกยอดเงิน = ยอดรวมออเดอร์ + ค่าจัดส่ง (ปรับได้ในหน้าเว็บ เพราะชีตยังไม่ได้แยกเก็บค่าส่ง)
* **ปุ่มพิมพ์บิล**: `window.print()` พร้อม CSS `@page { size: A4 }`
* **ปุ่มดาวน์โหลด PDF**: แปลงบิลเป็นภาพด้วย `html2canvas` แล้วสร้างไฟล์ PDF ขนาด A4 ด้วย `jsPDF` ดาวน์โหลดเป็น `ใบแจ้งหนี้-<เลขที่ออเดอร์>.pdf`

## 🖼️ โลโก้ร้าน

โลโก้ในหัวใบบิล (`.inv-logo-img`) เป็นไฟล์ภาพจริงของร้าน **ฝังเป็น Base64 data URI ไว้ในตัว `index.html` โดยตรง** (ไม่ใช่ไฟล์แยกในรีโป) เพื่อให้หน้าเว็บทำงานได้ครบในไฟล์เดียว ไม่ต้องพึ่งการโหลดไฟล์ภาพภายนอกเพิ่ม — หากต้องการเปลี่ยนโลโก้ในอนาคต ให้แปลงไฟล์ภาพใหม่เป็น Base64 แล้วแทนที่ค่าใน `src="data:image/png;base64,..."` ของ `<img class="inv-logo-img">`
